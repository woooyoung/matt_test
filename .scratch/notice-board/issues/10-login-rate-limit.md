# 10: 로그인 실패 제한

**What to build:** 같은 곳에서 로그인에 5번 연속 실패하면 15분 동안 로그인이 막히고, 로그인 화면이 잠시 뒤 다시 시도하라고 안내한다. 비밀번호 대입 공격을 늦추기 위한 것이다.

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 같은 IP에서 연속 5번 실패하면 이후 로그인 요청은 15분 동안 429 ProblemDetail과 `Retry-After` 헤더를 받는다(올바른 비밀번호여도)
- [ ] 15분이 지나면 다시 로그인할 수 있다. 주입된 시계로 차단 직전·직후를 검증한다
- [ ] 로그인에 성공하면 그 IP의 실패 횟수가 0이 된다
- [ ] 다른 IP의 실패는 서로 영향을 주지 않는다
- [ ] 실패 기록은 메모리에 두고 재시작하면 사라진다(인스턴스 1개 전제)
- [ ] Railway 프록시 뒤에서 실제 클라이언트 IP를 쓰도록 전달 헤더를 신뢰하게 설정한다
- [ ] 프론트 로그인 화면이 429를 받으면 차단 안내 문구를 보여준다(MSW 테스트)
