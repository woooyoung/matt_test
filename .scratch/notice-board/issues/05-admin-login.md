# 05: 관리자 로그인과 인증 유지

**What to build:** 관리자가 `/admin/login`에서 로그인하면 8시간 동안 로그인이 유지되고, 공개 화면에 관리자 버튼이 나타난다. 로그아웃하거나 로그인이 만료되면 버튼이 사라지고, 만료 뒤 관리자 작업을 시도하면 로그인 화면으로 안내된다. ADR 0002, 0003 참고.

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 관리자는 `ADMIN_USERNAME`, `ADMIN_PASSWORD_HASH`(BCrypt)로 정의되고 사용자 테이블은 없다. `local`·`test` 프로필은 설정 파일의 고정 계정을 쓴다
- [ ] `POST /api/auth/login` 성공 시 200과 `{accessToken, expiresAt}`. 토큰은 `JWT_SECRET`으로 서명되고 8시간 유효하다
- [ ] 로그인 실패는 아이디·비밀번호 중 무엇이 틀렸든 같은 문구의 401 ProblemDetail이다
- [ ] 현재 시각은 주입된 시계 하나에서만 얻는다. 테스트가 시계를 바꿔 만료 직전 토큰은 통과, 직후 토큰은 401임을 검증한다
- [ ] 보안 설정: 세션 없음, CSRF 꺼짐, 공지 GET과 로그인과 health만 공개, 공지 POST/PUT/DELETE는 `ROLE_ADMIN`, 그 밖은 거부
- [ ] 토큰 없이, 또는 위조된 토큰으로 공지 쓰기 요청을 보내면 401이다(아직 쓰기 엔드포인트가 없으면 보호 규칙을 테스트할 최소 경로로 검증)
- [ ] 프론트: 로그인 화면, 토큰을 `localStorage`에 보관, 모든 요청에 Bearer 헤더, 로그아웃 시 토큰 삭제
- [ ] 로그인 상태에서만 공지 목록·상세에 관리자 버튼("새 공지", "수정", "삭제") 자리가 보인다
- [ ] API가 401을 돌려주면 토큰을 지우고 `/admin/login?expired=1`로 이동해 "다시 로그인해 주세요"를 보여준다(MSW 테스트)
- [ ] 저장된 토큰이 만료 시각을 지났으면 로그인하지 않은 상태로 취급한다
