# 09: 공지 삭제

**What to build:** 관리자가 공지 상세에서 "삭제"를 누르고 확인하면 공지가 영구히 사라지고 목록으로 이동한다.

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] `DELETE /api/notices/{id}`(관리자): 204. 이후 같은 id 조회는 404
- [ ] 없는 공지 삭제는 404, 방문자의 삭제 요청은 401이다
- [ ] 프론트: "삭제"를 누르면 확인 다이얼로그가 뜨고, 취소하면 아무 일도 없다
- [ ] 확인하면 삭제 후 목록으로 이동한다
- [ ] 이미 삭제된 공지를 삭제하려 하면 "존재하지 않는 공지입니다"를 보여준다
