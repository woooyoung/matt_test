# 08: 공지 수정

**What to build:** 관리자가 공지 상세에서 "수정"을 눌러 기존 내용이 채워진 폼에서 제목과 본문을 고치면, 상세 화면에 바뀐 내용과 "수정됨 · 수정일시"가 보인다.

**Blocked by:** 06

**Status:** ready-for-agent

- [ ] `PUT /api/notices/{id}`(관리자): 06과 같은 입력 규칙, 200과 상세. `updatedAt`만 바뀌고 `createdAt`은 그대로다(주입된 시계로 검증)
- [ ] 없는 공지 수정은 404, 방문자의 수정 요청은 401이다
- [ ] 같은 공지를 두 번 수정하면 마지막 내용이 남는다
- [ ] 프론트 `/admin/notices/{id}/edit`: 기존 제목·본문으로 채워진 폼, 06과 같은 검증 안내, 저장 후 상세로 이동
- [ ] 상세 화면은 `updatedAt`이 `createdAt`과 다를 때만 "수정됨 · 수정일시"를 보여준다
- [ ] 수정 중 공지가 삭제됐으면 "존재하지 않는 공지입니다"를 보여준다
